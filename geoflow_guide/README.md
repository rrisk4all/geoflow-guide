# GeoFlow Guide 0.2.0

GeoFlow Guide identifies the active QGIS layer type and presents suitable,
plain-language tasks. It helps users complete common workflows without
searching through processing toolboxes or knowing algorithm names.

## Features

- Layer-aware recommendations for point, line, polygon and raster layers
- Plain-language descriptions before each action
- One-click zoom, attribute table, layer explanation, select and clear
- Native temporary outputs for buffer, centroids, geometry repair, vertices
  and geometry information
- Raster summary and display contrast enhancement
- CRS-aware buffers in metres or kilometres
- Generated-result history with selected-result removal
- Bundled point, line and polygon sample data
- Built-in help and compatibility self-check
- No external dependencies, account, internet connection or terminal setup
